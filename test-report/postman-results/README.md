# Postman API run evidence

Executed using Newman, Postman's collection runner, against the local API at `127.0.0.1:3001` with fictional records in a separate test database.

- `postman-run.json`: complete response and assertion data for every request.
- `postman-run.log`: readable runner output.
- `postman-run.html`: all requests, response statuses, timings, and assertion names.
- `screenshots/postman-run-results.png`: visual summary of the full run.

The import-ready collection is `postman/BESD-FN-023.postman_collection.json`. The required assignment database `se_course_db` was not used in this Postman run.
